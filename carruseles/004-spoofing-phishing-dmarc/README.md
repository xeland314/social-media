# Carrusel 004 · Spoofing y phishing

`proyecto.json` es un proyecto de **Cover Creator** (tema ambercat, acento naranja, 7 láminas).

1. Abre `/cover-creator` del portafolio (`npm run dev` en xeland314-portfolio).
2. Proyectos → **Importar JSON** → elige `proyecto.json`.
3. Cambia a formato Threads (4:5) o TikTok (9:16) y exporta cada lámina a PNG.
4. Guarda los PNG en esta carpeta como `01.png … 07.png`.

Todos los datos son ficticios (example.com, 203.0.113.0/24, evil.test).
